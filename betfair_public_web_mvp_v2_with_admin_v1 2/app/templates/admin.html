How resume works

Every Betfair source file has a stable processed-index key. Before downloading anything, the job checks whether its indexed Parquet object already exists in R2. Completed files are skipped; raw R2 files are reused; only missing raw files are downloaded from Betfair. You can safely rerun the same period after interruption.
